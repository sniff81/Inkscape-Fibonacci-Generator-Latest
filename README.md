# Inkscape-Fibonacci-Generator-Latest
Create a Fibonacci Spiral in Inkscape (1.4.4) from ANY object (v2.0)
<br><br>
Place both files in "extensions" folder (py,inx)
<br><br>
Extensions -> Render -> "Beauty Full Day Fibonacci Pattern"
<br><br>
v2.0: <br>
Added Option to stack items below/above
<br>
Added Input for Object Distance
<br>
Added Option for Aligning objects along circle angle
